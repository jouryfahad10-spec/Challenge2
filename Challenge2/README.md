#  Learning Journey 🔥

A simple iOS app that helps you stay consistent while learning a new skill. Set a learning goal and a duration, then log every day as Learned or Freezed to keep your streak alive.

Built with SwiftUI following the MVVM pattern.

Features
**Onboarding** (first launch only): choose what you want to learn and for how long (Week, Month, or Year). After the first goal is saved, the app opens directly on the Activity screen.
**Activity screen**: shows your current goal, today's date, the current week, and your Learned / Freezed counters.
**Log as Learned**: marks today as learned and increases your streak.
**Freeze for a day**: marks today as freezed so you keep your streak on a day you can't study. The number of freezes is limited based on the goal duration.
**Calendar**: a view-only calendar showing all previous learned and freezed days. History is kept even after you start a new goal.
**Goal completion**: when the duration ends, the app shows a result screen with a Set a goal button to start a new goal (the same one or a different one).
**Edit goal**: change the topic or duration at any time. If the goal is still in progress and you changed something, a confirmation warns you that your streak will start over. No warning is shown if nothing changed or if the goal has already ended.
